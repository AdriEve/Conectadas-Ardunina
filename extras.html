A Ardunina canta

Peças: Buzzer (D9) e LEDs (D4 e D7)

Ela canta Brilha, brilha, estrelinha, e os olhos piscam a cada nota.

const int olhoEsquerdo = 4;
const int olhoDireito = 7;
const int boca = 9;

// Notas de "Brilha, brilha, estrelinha" (vibrações por segundo)
const int notas[] = {
  523, 523, 784, 784, 880, 880, 784,
  698, 698, 659, 659, 587, 587, 523
};
// Duração de cada nota, em milissegundos
const int tempos[] = {
  400, 400, 400, 400, 400, 400, 800,
  400, 400, 400, 400, 400, 400, 800
};
const int totalDeNotas = 14;

void setup() {
  pinMode(olhoEsquerdo, OUTPUT);
  pinMode(olhoDireito, OUTPUT);
  pinMode(boca, OUTPUT);
}

void loop() {
  for (int i = 0; i < totalDeNotas; i++) {
    digitalWrite(olhoEsquerdo, HIGH);
    digitalWrite(olhoDireito, HIGH);
    tone(boca, notas[i], tempos[i]);
    delay(tempos[i]);
    digitalWrite(olhoEsquerdo, LOW);
    digitalWrite(olhoDireito, LOW);
    delay(60);
  }
  delay(2000);
}

O que tem de novo?

notas[] é uma lista de números. O for percorre a lista e toca uma nota de cada vez.

Experimente: Troque os números de notas[] para inventar outra música.

A Ardunina pisca

Peças: LEDs (D4 e D7)

Os olhos ficam acesos, e ela dá uma piscadinha com cada olho.

const int olhoEsquerdo = 4;
const int olhoDireito = 7;

void setup() {
  pinMode(olhoEsquerdo, OUTPUT);
  pinMode(olhoDireito, OUTPUT);
  digitalWrite(olhoEsquerdo, HIGH);
  digitalWrite(olhoDireito, HIGH);
}

void loop() {
  delay(2000);
  digitalWrite(olhoEsquerdo, LOW);
  delay(250);
  digitalWrite(olhoEsquerdo, HIGH);
  delay(2000);
  digitalWrite(olhoDireito, LOW);
  delay(250);
  digitalWrite(olhoDireito, HIGH);
}

O que tem de novo?

Apagar um olho de cada vez cria uma piscadinha. O delay() define quanto tempo ela dura.

Experimente: Mude os valores de delay() para ela piscar mais rápido.

A Ardunina dança

Peças: Servo (D11) e LEDs (D4 e D7)

O pescoço balança no ritmo, e um olho acende de cada vez.

#include <Servo.h>

const int olhoEsquerdo = 4;
const int olhoDireito = 7;
const int pinoPescoco = 11;

Servo pescoco;

void setup() {
  pinMode(olhoEsquerdo, OUTPUT);
  pinMode(olhoDireito, OUTPUT);
  pescoco.attach(pinoPescoco);
  pescoco.write(90);
}

void loop() {
  digitalWrite(olhoEsquerdo, HIGH);
  digitalWrite(olhoDireito, LOW);
  pescoco.write(70);
  delay(400);
  digitalWrite(olhoEsquerdo, LOW);
  digitalWrite(olhoDireito, HIGH);
  pescoco.write(110);
  delay(400);
}

O que tem de novo?

Várias peças mudam juntas: cada passo da dança define os dois olhos e o ângulo do pescoço.

Experimente: Troque 400 por 200. A dança fica mais animada?

A Ardunina fala robô

Peças: Buzzer (D9)

Ela faz sons de robô, e cada frase sai diferente da anterior.

const int boca = 9;

void setup() {
  pinMode(boca, OUTPUT);
  randomSeed(analogRead(A0));
}

void loop() {
  int sons = random(3, 8);
  for (int i = 0; i < sons; i++) {
    int duracao = random(60, 180);
    tone(boca, random(400, 1400), duracao);
    delay(duracao + 30);
  }
  delay(random(800, 2000));
}

O que tem de novo?

random() sorteia um número. Assim, a altura, a duração e a quantidade de sons mudam sozinhas.

Experimente: Mude os limites de random(400, 1400). A voz fica mais grave ou mais aguda?

O show da Ardunina

Peças: todas! Buzzer (D9), LEDs (D4 e D7) e servo (D11)

Ela canta uma música de videogame, dança balançando o pescoço e pisca um olho de cada vez, tudo no mesmo ritmo.

#include <Servo.h>

const int olhoEsquerdo = 4;
const int olhoDireito = 7;
const int boca = 9;
const int pinoPescoco = 11;

Servo pescoco;

// Melodia de videogame criada para a Ardunina (0 = pausa)
const int notas[] = {
  659, 784, 1047, 784, 659, 587,
  698, 880, 1175, 880, 698, 659,
  587, 659, 698, 784, 880, 988, 1047, 0
};
// Duração de cada nota, em milissegundos
const int tempos[] = {
  150, 150, 300, 150, 150, 300,
  150, 150, 300, 150, 150, 300,
  150, 150, 150, 150, 150, 150, 450, 300
};
const int totalDeNotas = 20;

void setup() {
  pinMode(olhoEsquerdo, OUTPUT);
  pinMode(olhoDireito, OUTPUT);
  pinMode(boca, OUTPUT);
  pescoco.attach(pinoPescoco);
  pescoco.write(90);
}

void loop() {
  for (int i = 0; i < totalDeNotas; i++) {
    if (i % 2 == 0) {
      digitalWrite(olhoEsquerdo, HIGH);
      digitalWrite(olhoDireito, LOW);
      pescoco.write(70);
    } else {
      digitalWrite(olhoEsquerdo, LOW);
      digitalWrite(olhoDireito, HIGH);
      pescoco.write(110);
    }
    if (notas[i] > 0) {
      tone(boca, notas[i], tempos[i] - 20);
    }
    delay(tempos[i]);
  }
  digitalWrite(olhoEsquerdo, HIGH);
  digitalWrite(olhoDireito, HIGH);
  pescoco.write(90);
  delay(1500);
}

O que tem de novo?

A cada nota, o código troca o olho aceso e o lado do pescoço. i % 2 == 0 descobre se a nota é par ou ímpar, e é isso que faz a dança ir de um lado para o outro.

Experimente: Troque os números de notas[] para criar a sua própria música de videogame. Com 0, a Ardunina faz uma pausa.
